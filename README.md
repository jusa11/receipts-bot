# Учёт покупок по чекам — локальный этап OCR

Локальный Telegram-бот принимает фото чека, отправляет его в официальный Yandex Vision OCR и сохраняет исходное изображение, полный ответ OCR и извлечённый текст в `data/`. Этот этап **не** разбирает товары через LLM и не записывает данные в Google Sheets.

Telegram работает через long polling: для локального запуска не нужен публичный сервер или webhook. Обрабатываются только Telegram ID из allowlist.

## Требования

- Python 3.11 или новее.
- Токен Telegram-бота от BotFather.
- Yandex Cloud: API-ключ с разрешением Vision OCR, роль `ai.vision.user` и ID каталога.

## Запуск в Windows PowerShell

```powershell
Copy-Item .env.example .env
```

Заполните `.env`: `TELEGRAM_BOT_TOKEN`, `ALLOWED_TELEGRAM_USER_IDS` (ваш числовой Telegram ID), `YANDEX_API_KEY` и `YANDEX_FOLDER_ID`. Затем запустите:

```powershell
.\.venv\Scripts\python.exe -m receipt_bot
```

Unit-тесты:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Зависимости сторонних пакетов отсутствуют: используется стандартная библиотека Python. Учетные данные не следует отправлять в чат или коммитить в Git.

## Сценарий

1. Узнайте свой числовой Telegram ID (например, в настройках Telegram-клиента или через бота, показывающего ID пользователя).
2. Внесите ID в `ALLOWED_TELEGRAM_USER_IDS`, запустите приложение и напишите боту `/start`.
3. Бот вернёт распознанный текст и локальный ID обработки.
4. Проверьте запись в `data/receipts/<id>/`: `receipt.json`, `ocr-response.json` и исходное фото.

Повторная доставка того же Telegram-сообщения не вызывает повторный запрос OCR, если его результат уже сохранён. Ошибку распознавания можно повторить, переслав фотографию новым сообщением. Удаляйте `data/` вручную, если хотите стереть локально сохранённые изображения и результаты.

Поддерживаются фотографии Telegram и отправленные как файл JPEG, PNG или PDF. Vision OCR принимает изображения до 10 МБ и до 20 мегапикселей. Синхронный режим OCR для PDF поддерживает одностраничные документы; для многостраничных PDF понадобится отдельный асинхронный этап.

## Границы текущего этапа

- Yandex Vision OCR выполняет только распознавание текста; категории и бизнес-логика в него не передаются.
- Месяц, неделю и «цену план» бот не заполняет.
- Google Sheets, Алиса GPT, арифметические проверки и запись в таблицу пока не подключены.
- Передача изображения в OCR выполняется только после отправки фото боту; локальная копия остаётся в `data/`.

## Формат хранения

`receipt.json` содержит Telegram chat/message IDs, время получения, имя файла, статус и OCR-текст. `ocr-response.json` сохраняет исходный JSON Yandex Vision OCR с координатами блоков и строк. Токены и API-ключи в эти файлы не записываются.
